# Developer Guide

Canonical domain types belong under `internal/core`. Forge, KLIQ and Correlate modules must reuse those types instead of redefining risk, finding, evidence, conformance, capability, grant or runtime-action concepts.

For the PG-14 to PG-16 review split, see [PG-14 to PG-16 PR Slices](pr-slices-pg14-pg16.md).
